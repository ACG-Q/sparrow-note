# 12 · 「我的」与四个子页面改版

## 一句话

把「我的」从一张设置清单改成**一册账本的扉页**：一枚印是你，四个数字是这本账的规模，一条跨度是落款，右边一页是目录。四个子页面共用同一张纸的外壳，桌面上用页边标签排版。

## 用户与任务

- 谁：自己记日记的人，手机上随手看，电脑上偶尔整理。
- 首屏要看到什么：记了多少（笔记 / 心情 / 联系人 / 纪念日）、记了多久。
- 首屏要能做什么：改昵称、进四个子页面。
- 不做什么：不做社交、不做账号、不放云同步入口。

## 方向

品牌资产不动：纸色底、墨色字、印章红、宋体 + 等宽小字、零圆角、1px 发丝线。改的是**骨架和信息密度**：

- 以前「我的」= 昵称行 + 5 行统计表 + 4 行入口，全部同级、全部一样重。
- 现在按「扉页」的三段式：**身份（印）→ 规模（数字）→ 目录（入口）**，三段的分量依次递减。

## 结构

### 手机（< 1024px，实测 360px）

```
我的                                  [目录]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 2px

[雀]  留个名字
      点一下就能改，20 字以内

 1 篇 │ 0 条 │ 0 位 │ 0 个      ← 四个数字等分，发丝竖线分隔
 笔记   心情   联系人  纪念日

记录跨度        2026 年 10 月 30 日 - 30 日

目录
个性化 …………………………… 浅色 · 标准 →
权限   …………………………… 6 项 →
设置   …………………………… Android →
关于   …………………………… v0.1.0 →
```

### 桌面（≥ 1024px）

左右对开，中间一条装订线：

- 左页：印 + 昵称、四个数字（2×2，数字放大到 38px）、记录跨度
- 右页：目录，条目加高到 62px、标签 19px，右侧值 11px

### 子页面（个性化 / 权限 / 设置 / 关于）

- 共用 `app/ProfileShell.tsx`：留白、返回、标题、右侧标记、2px 底线只写一次。
- 桌面 ≥ 1024px 时分区标题变成**页边标签**：132px 左栏放「外观 / 阅读与条目 / 纪念日提醒」，正文在右栏，区块之间用 1px 横线分隔，像印刷品的边注。
- 权限页不是 `.block` 结构，单独把正文缩到与其它页同一条左界（164px 偏移，720px 可读宽度）。

## 关键状态

| 状态 | 处理 |
|---|---|
| 没填昵称 | 印章里放品牌字「雀」，空心章；不留一块看着像加载失败的白纸 |
| 昵称改了 | 失焦或回车即存，提示从「点一下就能改」变成「已保存」，1.6s 后复原 |
| 完全没有笔记 | 记录跨度显示「还没有记录」，不显示空值 |
| 有新版本 | 关于那一行点一枚 5px 印泥红点，值变成「新 0.2.0」 |
| 浏览器里 | 设置页标记显示「浏览器」，存储区块降级为 IndexedDB 说明 |

## 交互

- 昵称输入框：聚焦时下划线转印章色；回车收起键盘并保存（移动端 `enterKeyHint="done"`）。
- 目录条目：点按整行，箭头右移 2px、标签与箭头转印章色（0.16s）。
- 子页面返回：`← 我的` 的可点区域在手机撑到 44px 高，桌面收回到文字高度。

## 做的减法

- 删掉常驻的「保存」按钮（90% 的时间它都在那儿却什么也没改），改成失焦即存。
- 删掉入口行里的关键词串（「外观 · 阅读 · 汇总分类」）——换成**当前值**（「浅色 · 标准」「6 项」「Android」「v0.1.0」），入口本身就带信息。
- 删掉标题行的版本号，版本只在「关于」出现。
- 删掉四个子页面各自抄的一份页头样式，统一进外壳（`SettingsView.module.css` 少了 53 行重复定义）。
- 分段控件格子定宽 80px：所有行右边缘对齐后，左边缘的锯齿也小了很多。

## 评审（一轮，10 分制）

独立评审者只看截图、不看代码，初版给 **6.3 / 10**（信息层级 6.0、排版 6.5、字体 7.0、细节状态 5.5、移动 6.0、桌面 6.0、气质 7.0）。
结论里最狠的三条都成立，已按它改：

| 评审意见 | 处理 |
|---|---|
| 「我的」桌面 4 行目录（20px、57% 宽度）压过了真正的主角，下半屏 52% 空着 | 改成单列：四个数字放大到 48px 占满整条，目录收成 **两栏索引**（18px），高度也补上 |
| 印章红超支：勾选框实心红、存放位置红框、权限角标，「良性项用红、危险项只有细描边」 | 红只留给危险操作与唯一的主操作：勾选改墨色、选中卡改左侧墨条、行内「申请权限」改墨色描边，一屏只留一处实心红 |
| 权限页的核心状态（授权与否）是全页最小的字，「全部申请」面板最响 | 状态字号 9→11.5px 并靠右对齐到标题同一行；汇总面板从填充块改成上下发丝线的一行；行内按钮降级 |
| 角落标签四页四义（本机 / 浏览器 / Windows 桌面端 / v0.1.0） | 统一为 `platformLabel()`，版本只在「关于 · 更新 · 当前版本」出现一次 |
| 关于页三行长句右对齐读不下去；更新地址/检查更新主次颠倒；「编辑地址」双线 | 三行改「标签上、说明下」左对齐；检查更新做成主按钮；「尚未检查」从填充条改成一条细线；按钮与行线拉开距离 |
| 移动端 40×40 目录框、32×32 段控件、11px 返回 | 目录框 44×44、段控件 36px 高、返回 12px；选中态加一道 1px 深线 |
| 三级标题只差 1px | 章节 13px 衬线 / 子块 10px 等宽 / 行标签 13.5px，靠字体而不是字号区分 |
| 360px 上「代码块折叠」控件顶到标签 | ≤380px 时行距收 10px、标签 12.5px、格内边距 9px，四选项一行放得下 |

评审也点出「不要动」的部分，都保留了：纸/墨/印章三色与发丝线、宋体 + 等宽字距、40px 数字对 13px 标签的对撞、
360 真机一屏装下、目录点线（但删掉了箭头之外的杂物）、权限页「一句人话 + 技术元信息 + 提示」的结构。

## 没做的

- 评审提到的「设置页在浏览器里勾着自动备份却不可能生效」属于行为问题，这一轮没动（改动涉及备份开关的禁用逻辑与文案，单独做更稳）。
- 「我的」桌面下半屏仍有约 40% 空白：这一页信息量本来不多，宁可留白也不塞占位内容。
- 顶部 35px 工具条（导航 / 锁定 / 夜间纸）不属于这一族页面，未动。
