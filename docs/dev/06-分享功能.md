# 分享功能

阅读页的 `⋯` 菜单里有四项导出：Markdown 单文件、Markdown + 附件 zip、PDF（矢量文字）、长图。

## 入口

桌面（Viewbar 的 `⋯`）和手机（窄屏顶栏的 `⋯`）**共用同一组菜单项**——
抽成了 `src/components/ShareMenuItems.tsx`，样式各自沿用自己那套 `className`。

之前手机上没有，是因为窄屏走的是 App 里另一套顶栏（`isNarrow` 分支），
它的 `popMenu` 里只有「改日期 / 删除笔记」，分享项一个都没挂。


阅读态右上 `⋯`：
- 导出 Markdown（单文件）
- 导出 Markdown + 附件（zip）
- 导出 PDF
- 导出长图 ›（二级：窄 480 / 标准 720 / 宽 960）
- 打印 / 另存为 PDF
- 删除这篇

## Markdown：两种形态

| 形态 | 附件怎么处理 | 文件 |
|---|---|---|
| 单文件 | 内联成 base64 data URL，一个文件拿走全部 | `标题.md` |
| 压缩包 | 落到 `assets/1-pic.png`，正文写相对路径，再打包 | `标题.zip`（内含 `标题.md` + `assets/`） |

序列化在 `src/lib/share.ts`，自己写而不是用 BlockNote 的 `blocksToMarkdown`：
后者要求现成的编辑器实例和 PM schema，而阅读态根本没有编辑器。

覆盖的块：标题（层级）、段落、有序/无序/勾选列表（含子块缩进）、引用、代码块（带语言）、
表格（GFM，竖线转义、自动补空列）、图片/视频/音频/文件/手绘、分隔线，以及
自定义块（`> **心情**：喜` 这种形式，语音块会把音频一起导出）。

## PDF：pdf-lib + 内置中文字体（矢量文字）

自己实现了排版引擎（`src/lib/pdfDoc.ts`），不用 html2pdf 之类——它们最后还是把中文栅格化。

覆盖：标题层级、段落（含粗体/代码底/链接下划线）、列表、引用（左边线）、代码块（底色 + 硬折行）、
**表格（等宽列 + 边框 + 单元格折行 + 跨页重复表头）**、图片、自定义块、分隔线。

### 字体

| 文件 | 覆盖 | 大小 |
|---|---|---|
| `sparrow-sans-sc.ttf` | GB2312 一级 + 二级（7719 字）+ 拉丁 + 标点 | 1.90 MB |
| `sparrow-sans-sc-bold.ttf` | GB2312 一级（4711 字） | 1.13 MB |

粗体是**真的粗体字重**，不是重复绘制模拟——之前用偏移重绘，复制出来是「加加加粗粗粗」。
粗体子集只收一级汉字，遇到缺字自动退回常规体，不会出现空白方框。

生成脚本：`scripts/subset-font.mjs`（`subset-font` + GB2312 码表，构建期一次性跑）。

### 体积

字体和库都是**按需加载**（点导出才拉），不影响首屏：

```
sparrow-sans-sc.ttf       1.94 MB
sparrow-sans-sc-bold.ttf  1.16 MB
pdf-lib                   430 kB（gzip 129 kB）
fontkit                   711 kB（gzip 330 kB）
```

Tauri 打包时这些仍会进安装包，**约 +4.2 MB**。

### 实测

```
单页笔记   408ms，31KB，pdfjs 抽出 85 个字符的中文
长文 70 段  3 页，70KB，抽出文本含「第 1 段」…「第 70 段」，无丢失
长表格 46 行 2 页，两页都有表头「姓名/金额」，最后一行还在
```

### 什么时候还会用到打印

`printNode()` 还留着（`@media print` 样式也在），但菜单里没挂——矢量 PDF 已经覆盖它的用途。

## 打印 / 另存为 PDF

菜单里也保留系统打印这一项：翻页由打印引擎控制（比我们自己切的页更贴 A4 排版），
打印样式里加了 `break-inside: avoid`（图片、表格行、引用、代码块不跨页）、
标题不与下文分离（`break-after: avoid`），并隐藏打印稿里的按钮。

清理时机：`afterprint` → 窗口重新获得焦点 → 30 秒兜底，三重保证不会把页面留在打印态。

## 长图

SVG `<foreignObject>` 把克隆出来的阅读态 DOM 连同样式一起渲染进 canvas（2 倍图），
不用 html2canvas（1MB+ 且中文排版经常错）。

样式是整站 `document.styleSheets` 复制过去的，CSS Modules 的类名在克隆节点里一致；
`:root` 上的 CSS 变量单独抄了一份（SVG 里没有 `:root` 可匹配）。

## 已知限制

- 生僻字超出 GB2312 二级时，PDF 里可能缺字（子集没收录）
- 单文件里如果有几百 KB 的音频，`.md` 会变得很大（这是内联的代价）
- 外链图片保持原 URL，PDF 里不会去下载
- 表头重复只支持「一行表头」

## 测试脚本

`review/share-check.mjs`（端到端）、`share-verify.mjs`（字节校验）、
`share-vector-pdf.mjs`（pdfjs 抽文本）、`share-long.mjs`（长文分页）、`share-table.mjs`（表格）。
