可以试这些

  1. 点单元格打字；工具条上的 ＋行 ＋列 会在当前格子下方/右侧插入
  2. 点最左的 ▦ 3×3 → 网格拖选或直接填数字 → 确定
  3. 点 ≡左 / ≡中 / ≡右 给光标所在整列对齐
  4. 点 ⋯：合并右侧单元格、拆分、删本行、删本列、删除表格
  5. 鼠标移到表格左侧的 ⋮⋮：块菜单里也有一份表格命令
  6. 下面两个按钮用来验证「表格滚动时工具条不动」
