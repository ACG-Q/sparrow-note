# 麻雀记 (Sparrow Diary) - 项目规划

## 项目定位
跨平台、本地优先的**日记/生活记录**应用。核心是以**时间线**组织生活碎片，按日期分组展示各类记录。

## 技术栈

| 层级 | 技术 |
|------|------|
| 框架 | Flutter 3.x + Dart 3.x |
| 架构 | Clean Architecture + MVVM |
| 状态管理 | Riverpod |
| 数据库 | drift (类型安全 SQLite) |
| 路由 | go_router |
| 地图 | flutter_map (OpenStreetMap) |
| 富文本 | flutter_quill (textV2) |
| 云同步 | WebDAV (webdav_plus) + AES-256-GCM 加密 |
| 录音 | record |
| 主题 | Material Design 3 + 动态取色 |

## 支持平台
Android / iOS / Windows / Linux / macOS（**不支持 Web**）

---

## 核心交互范式

```
主页 = 时间线       ← 日记流，按日期分组
         ↓
FAB → 选择类型     ← 13 种记录类型
         ↓
编辑条目 → 保存    ← 自动归入对应日期
         ↓
日历入口           ← 快速跳转到特定日期
```

## 功能总览

### 13 种记录类型（可混搭在同一天）
1. 文本 (text) - 纯文本 + 附件（图片等）
2. 富文本 (textV2) - Quill 富文本，含图片/视频内嵌块
3. 清单 (checklist) - 待办事项列表
4. 心情 (mood) - 情绪记录
5. 链接 (link) - 自动抓取标题和封面
6. 日子 (anniversary) - 纪念日 / 节日 / 计时（含倒数日）
7. 位置 (location) - 地图选点记录地址
8. 绘画 (drawing) - 简单画板
9. 银行卡 (bankCard) - 结构化卡片信息
10. 联系人 (contact) - 联系人信息
11. 账号 (account) - 网站/应用账号密码
12. 语音 (voice) - 录音存储
13. 日程 (calendar) - 日历视图日程

### 组织管理
- 标签 (Tag) - 分类标记（替代文件夹），多对多关联

### 系统功能
- 时间线 / 日历 / 看板 三种视图
- 全局搜索（标题/内容/标签/类型过滤）
- 仪表盘（Dashboard，可配置组件）
- 本地备份 / WebDAV 云备份（AES 加密）
- 夜间模式 / 多主题（6 套 + 自定义）
- 应用锁（规划中，coming soon）

## 数据库核心表

于 `lib/data/database/app_database.dart`（schemaVersion = 4）：

```
Notes                     ← 记录主表
├── id          TEXT PRIMARY KEY
├── title       TEXT
├── content     TEXT (JSON, 按类型存储不同结构)
├── type        TEXT (NoteType 枚举值)
├── date        TEXT (YYYY-MM-DD, 按日期分组)
├── weather     TEXT
├── is_pinned   BOOL
├── created_at  DATETIME
└── updated_at  DATETIME

Tags               ← 标签
├── id, name, color, created_at

NoteTags           ← 笔记-标签关联（多对多）
note_id + tag_id   （联合主键）

DashboardConfigs   ← 仪表盘组件配置
section_id / sort_order / visible / settings(JSON)
```

### Iteration 6 ✅ - 系统功能
- 本地备份 / 云端备份（AES 加密 + 定时器）
