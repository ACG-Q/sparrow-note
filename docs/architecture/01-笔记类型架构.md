# 笔记类型架构

> 本文档描述笔记类型分层的**实现现状**，是 `dev/02-笔记类型UI规范.md` 的对照落地结果。新增/修改笔记类型请遵循规范文档。

---

## 一、整体架构

笔记类型采用四层结构，每层对应一个类型化 data class 与一组 widget：

```
NoteType (enum)
    │
    ├── XxxData (data class)     ← 类型化数据模型（domain/note_data）
    ├── XxxEditor (widget)       ← 编辑器面板（editors/）
    ├── XxxCard (widget)         ← 卡片预览（cards/，timeline / dashboard）
    └── XxxPreview (widget)      ← 完整预览（previews/，可复用 XxxCard）
```

### 三阶数据流

```
用户操作 → Editor → onChanged(data) → NoteEditorPage 持有 data → 保存时 toJson() → DB
DB       → Note(content: json) → dispatch → XxxData.fromJson(json) → Card / Preview
```

JSON 解析在 dispatch 处一次性完成，各层只操作类型化 data。

## 二、实现现状

### 2.1 类型清单（13 种）

`enum NoteType` 定义于 `lib/domain/enums/note_type.dart`：

| NoteType | data class | 文件 |
|----------|-----------|------|
| text | `TextData` | `text_data.dart`（`text` + `attachments`，图片为附件） |
| textV2 | `TextV2Data` | `text_v2_data.dart`（flutter_quill Delta 富文本 + 标题） |
| checklist | `ChecklistData` | `checklist_data.dart` |
| mood | `MoodData` | `mood_data.dart` |
| link | `LinkData` | `link_data.dart` |
| anniversary | `AnniversaryData` | `anniversary_data.dart`（category: day/timer/festival，承担倒数日） |
| location | `LocationData` | `location_data.dart` |
| drawing | `DrawingData` | `drawing_data.dart` |
| bankCard | `BankCardData` | `bank_card_data.dart` |
| contact | `ContactData` | `contact_data.dart` |
| account | `AccountData` | `account_data.dart` |
| voice | `VoiceData` | `voice_data.dart` |
| calendar | `CalendarData` | `calendar_data.dart` |

> 无独立 image / countdown 类型：图片为 text 附件与 textV2 内嵌块；倒数日由 anniversary 承担。
> 全部类型 `isImplemented == true`，无占位枚举。

### 2.2 目录结构

```
lib/
├── domain/
│   ├── enums/note_type.dart          ← NoteType 枚举 + 显示元数据
│   └── note_data/                    ← 13 个 data class + barrel 导出
├── core/utils/json_helpers.dart      ← safeDecode 统一 JSON 解析
├── features/
│   ├── notes_list/widgets/
│   │   ├── entry_card.dart           ← 列表卡片 dispatch
│   │   └── cards/                    ← XxxCard（按类型）
│   └── notes/
│       ├── views/
│       │   ├── note_editor_page.dart  ← 编辑器 dispatch
│       │   ├── note_preview_page.dart  ← 预览 dispatch 入口
│       │   └── previews/            ← XxxPreview（每类型一个）
│       └── widgets/editors/          ← XxxEditor（按类型）
```

### 2.3 关键实现点

| 方面 | 说明 |
|------|------|
| JSON 解析 | `safeDecode` 收敛于 `core/utils/`，各处复用，无重复 `_parseJson` |
| 预览拆分 | `note_preview_page.dart`（317 行）仅做 dispatch，渲染委派各 `XxxPreview` |
| 富文本 | textV2 走 `flutter_quill`（Delta），text 走纯文本 + 附件；两者编辑器、卡片、预览、备份收集均独立 |
| 图片查看器 | `lib/features/notes/widgets/image_viewer_page.dart`：多图 PageView + 缩放（1.0–5.0x）+ 90° 步进旋转 |
